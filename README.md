# Sorteo Plus

Este repositorio contiene una aplicación web llamada **Sorteo Plus**, desarrollada con HTML, CSS y JavaScript.  
El proyecto forma parte de mi portfolio como desarrollador frontend.

---

## 📌 Descripción

**Sorteo Plus** es una herramienta web interactiva que permite generar números o resultados aleatorios para sorteos directamente en el navegador.  
La aplicación está construida utilizando JavaScript para la lógica de sorteos y una interfaz visual simple para la interacción del usuario.

El objetivo del proyecto es practicar lógica condicional, manipulación del DOM y diseño de interfaces con JavaScript.

---

## 🛠️ Tecnologías utilizadas

- HTML5  
- CSS3  
- JavaScript  
- Git y GitHub  

---

## 🧩 Funcionalidades

- Generación aleatoria de resultados
- Interfaz de usuario sencilla e interactiva
- Estilos visuales claros
- Funcionamiento 100% en el navegador
